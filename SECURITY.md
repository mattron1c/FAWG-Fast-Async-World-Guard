# Security policy

## Supported versions
Only the latest release receives fixes.

## Reporting a vulnerability
Please **do not open a public issue** for protection bypasses or exploits (duplication, griefing through a
region, permission escalation). Report them privately through
[GitHub security advisories](https://github.com/mattron1c/FAWG-Fast-Async-World-Guard/security/advisories/new).

Include the FAWG version, server version, the flag / region setup and exact reproduction steps. You will get
an answer as soon as possible, and a fix will be released before details are made public.
